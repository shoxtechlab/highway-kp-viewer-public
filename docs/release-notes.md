# 変更履歴

[ドキュメント案内](README.md#変更履歴版番号) / **変更履歴**

公開アプリの主要な変更を、日付と機能ごとにまとめています。日付は日本時間です。細かな文言・配置の試行はGit履歴で確認し、この資料では最終的な動作を説明します。

## 2026年11月7日 — 位置公開と走行画面の運用整理

対象版：`2026.11.7-beta.1`〜`beta.10`

| 機能 | 更新内容 |
| --- | --- |
| 走行ヘッダー | スマホ縦画面は左に路線名と小さめの位置公開操作、右に表示設定・走行終了を配置。長い路線名は残り幅で文字サイズを調整し、ヘッダーを低く整理。横画面は計器盤と路線図の2列を維持 |
| 公開状態の表示 | 本線外のボタンは「位置公開待機中」。待機中は白背景・赤枠・赤文字、公開中の「位置公開を停止」は赤背景・白文字。下部の1行表示にも状態を明示 |
| 他車両の閲覧 | 初期オフへ変更。オンにした画面だけが定期取得し、手動で保存した選択は維持 |
| iPhoneの上端 | 通常ビューと同じ背景構造を使い、ライト時のステータスバー背面をヘッダーの緑へ統一 |
| 架空デモ車 | E28・E30・E76の出発KP・方向・速度・開始／停止を管理者が設定可能に。開始から1時間で自動停止し、実利用者とは🚙で区別 |

操作の詳細：[走行モード](drive-mode.md) · [位置公開・他車両表示](live-locations.md)

## 2026年11月6日 — 位置公開、編集・閲覧機能の拡充

対象版：`2026.11.6-beta.1`〜`beta.30`

| 機能 | 更新内容 |
| --- | --- |
| 位置公開 | 走行モードから明示的に公開を選択・停止できる機能を追加。匿名の番号・方向・0.1KP表示、10秒更新・30秒失効に対応。起動時は非公開で、公開操作時だけ確認する構成へ整理 |
| 車両表示とデモ | 通常路線図の最前面に🚗を描画。デモURLからの仮想位置公開と、サーバー側で位置を計算する往復デモ車を追加。デモは🚙で区別 |
| 編集・ファイル操作 | 細かいKP入力、起点KP順の一覧、追加／更新の操作整理、CSV・JSONの直接読込・書出、確認付き全削除に対応 |
| 地点の写真 | 全路線の端末保存の地点へ写真添付を展開。写真込みZIPでの持ち運びに対応。共有画像は未対応のまま、誤った共有保存を拒否 |
| 通常の路線図 | 縮尺に応じた0.1・0.5・1・5・10KP目盛りと10倍までの拡大。橋梁・トンネルの諸元表示を全路線へ展開し、同名構造物や管理区間での切り詰めに対応。諸元パネルを小型化 |
| 本線外の走行表示 | 現在地KPを`--`、参考の位置を灰色で区別。別路線の最寄りKPを開いていた路線の現在地として流用しない |
| 印刷・ナビゲーション | iPhone・iPadのホーム画面アプリでは戻る操作付き印刷プレビューを使用。本四・事務所版の戻り先を路線API読込前に確定 |

操作の詳細：[編集モード](user-annotations.md) · [写真保存の設計](annotation-images-design.md) · [諸元表示](structure-details.md)

## 2026年11月5日 — 走行モードの基本動作を整備

対象版：`2026.11.5-beta.1`〜`beta.17`の主要変更。

- **開始と本線外**：事前の測位待ちをなくし、最初の有効判定を暫定表示。許可拒否・本線外でも路線図を閲覧可能に。
- **GPSロストとトンネル**：10秒で未更新警告、一般区間は30秒まで推定。登録済みトンネルは出口まで推定し、復帰測位の整合を検証。
- **画面とデモ**：スマホ横画面の2列配置と施設名の表示を調整し、トンネル内ロスト・出口待ちの固定デモを追加。
- **構造物の諸元**：E30・E18で試験導入し、KPの表示桁数・延長の丸め・OSM由来延長の除外を整理。

## 版番号とソースの対応

ベータ版は`YYYY.M.D-beta.N`形式です。日付と同日の公開順を表すもので、機能の大小は表しません。公開ドキュメントは複数の細かな版を機能単位でまとめますが、アプリ自体の版番号は省略しません。

公開ソースは別途スナップショットとして更新します。更新時点は `PUBLIC-SNAPSHOT.json`、稼働中の版は[公開アプリの版番号](https://highway-kp-viewer.pages.dev/app-version.json)で確認できます。公開リポジトリへ非公開側の全履歴をマージする構成ではありません。

今後の候補は[プロジェクト概要の改善候補](../README.md#8-改善候補)へ分け、実装済みの変更と混在させません。
