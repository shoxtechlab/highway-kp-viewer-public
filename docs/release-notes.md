# 変更履歴

公開アプリの主要な変更をまとめています。日付は日本時間です。実装済みの挙動は各操作ガイドを参照してください。将来の改善候補とは分けて記録します。

## 2026年11月6日

対象版：`2026.11.6-beta.1`〜`beta.11`

- 編集モード：KP入力の刻み制限を解除し、追加済み一覧を起点KPの数値昇順へ変更。
- 編集モード：CSV・JSONの直接読込と形式を選べる書出、確認付き全削除を追加。
- 編集モード：主ボタンを「追加する／変更を保存」に整理し、編集状態・編集中止・独立した保存通知を追加。
- 通常ビュー：目盛り間隔を0.1・0.5・1・5・10KPから自動選択し、単位をKPへ統一。拡大上限を10倍へ変更。
- 走行モード：本線外の現在地マーカー非表示を修正し、現在地KPを`--`へ変更。取得できた速度は表示。
- 走行モード：本線外では開いていた路線を維持し、灰色の横線と選択位置・最寄り位置・閲覧位置で参考表示を区別。
- 文書：走行モード、編集モードのファイル形式、公開範囲、デモの案内を再整理。
- 通常ビュー：橋梁・トンネルの諸元表示を全路線へ拡大。同名構造物は区間・始終点等から作るキーで識別し、管理範囲で切り詰めても原本の諸元へ紐付け。
- 編集モード：E28の地点・端末保存に限り写真添付を試験導入。写真込みZIP入出力を追加し、従来CSV・JSONと既存端末データを維持。共有画像は未対応。
- 編集モード：写真添付・写真込みZIPを全路線の地点・端末保存へ展開。共有APIは未対応の写真投稿を明示的に拒否し、メタデータの消失を防止。
- 通常ビュー：KP入力欄の例示文字のみ約25%縮小。入力値の文字サイズは維持。

## 2026年11月5日

対象版：`2026.11.5-beta.1`〜`beta.17`のうち、以下の変更を収録。

- 走行モード：GPS未更新10秒で警告し、通常区間の推定時間上限を30秒へ変更。
- 走行モード：初回の有効判定を暫定表示し、次の判定で確認・補正する起動処理を追加。
- 走行モード：スマートフォン横画面の2列配置とラベル文字サイズを調整。
- 走行モード：GPSの事前取得を待たず開始し、本線外や許可拒否時も参考閲覧できる入口へ変更。
- 走行モード：登録済みトンネルでは出口を上限に推定を継続し、GPS復帰時に整合を確認。
- 走行モード：URLで指定するトンネル内GPSロストの固定デモを追加。
- 通常ビュー：E30・E18の橋梁・トンネル諸元ポップアウトを試験導入。OSM由来延長を除外し、KPを小数第3位、延長を1m単位に丸めて表示。

## 版番号と公開ソース

ベータ版は`YYYY.M.D-beta.N`で付番します。同じ日の連番であり、機能の大小を表す番号ではありません。過去の`26.0.0-beta.*`表記とは形式が異なります。

公開ソースは別途スナップショットとして反映します。この変更履歴は公開アプリの動作を説明するもので、公開リポジトリにすべての該当コミットが存在することを意味しません。
