## 変更履歴・版番号

- [変更履歴](release-notes.md)：日付ごとに機能単位で整理した、利用者向けの更新概要。
- [版番号の方針](../VERSIONING.md)：`YYYY.M.D-beta.N` の意味と、コードの版との対応。
- [現在公開中の版](https://highway-kp-viewer.pages.dev/app-version.json)：実際に配信されているアプリの版番号。
- 公開リポジトリの `PUBLIC-SNAPSHOT.json`：公開ソースを切り出した時点と収録ファイル。

細かな余白・文言の試行履歴はGitへ残し、変更履歴には完成した機能としてまとめます。公開ソースの履歴と開発元の全コミットは同一ではありません。

## 資料の読み方と公開範囲

スクリーンショットは構成例です。版が古い画像ではその旨を添え、現在のボタン名や状態表を本文に記載します。画像はE28またはE30を用い、元の画像を拡大して確認できます。

実装済みの説明と将来案を分けています。特に画像のクラウド共有、機器専用の認証・表示名は、現在の機能として案内しません。位置公開は利用者同士の限定ルームではなく、サイト閲覧者に向けた公開です。

内部の加工資料・工程別画像・補正点・認証キー・管理者向け操作リンクは、この公開ドキュメントの案内対象外です。一般的なAPIの位置変換と、非公開のデータ作成工程は区別しています。
