## 文書の対象範囲

各操作ガイドは文頭の対象版を基準にします。スクリーンショットは画面構成の参考で、最新の文言やボタンと差がある場合はその旨を記載します。固定デモはGPS不要ですが、初回の路線読込にはネットワークを使用します。

公開リポジトリはソースのスナップショットとして更新しています。公開アプリの最新実装と、公開ソースの更新時点が一致するとは限りません。

OSMの詳細な抽出・補正手順、補正点、内部Viewerの工程別画像はこの公開資料に含めません。公開APIの一般的な位置変換計算と、非公開のデータ作成工程を区別しています。
