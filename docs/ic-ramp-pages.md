# ICランプページ — 路線図からIC内部へ

ICランプページは、インターチェンジ周辺を上から見た図にランプ線形を重ね、個々のランプから現地の Street View を開くための試験機能です。

![津名一宮ICのランプページ。A〜Dランプを色分けして表示](e28-tsuna-ichinomiya-ramp-light-pc.jpg)

縦長の路線図は「どの施設が何KPにあるか」を見るのに向いています。一方、ICの内部には複数の流入・流出ランプがあります。そこで、ICラベル内の小さなボタンを入口にして、必要なときだけ詳細ページへ進む二段構成にしています。

```text
E28路線図 → ICラベル内のランプボタン → IC俯瞰図 → 各ランプのStreet View
```

## 公開範囲

現在、公開サイトでは **E28 津名一宮IC** のみをベータ公開しています。

- [津名一宮IC ランプページ](https://highway-kp-viewer.pages.dev/prototypes/ic-ramps/?ic=tsuna-ichinomiya)
- E28の路線図では、津名一宮ICラベル内の小さなランプボタンから開けます。

ほかのIC・JCT用に作成中の抽出結果や確認用データは、精査が終わるまで公開リポジトリと公開ビルドには含めません。

## 画面の使い方

1. 色分けされたランプを選択します。
2. 選択中のランプ、方向、出入口の種別を確認します。
3. Street Viewボタンを押すと、そのランプ付近のGoogle Mapsを新しい画面で開きます。
4. 戻るボタンで、元の路線図と表示位置へ戻ります。

路線図そのものを複雑にせず、詳細情報だけを後から足せるのがこの方式の利点です。将来は、料金所を起点にしたメーターポスト（MP）、ランプ名称、分岐・合流位置などもIC単位で段階的に追加できます。

ランプ名称は路線ごとの管理上の呼称に合わせます。上り・下りとA〜Dランプの対応は道路会社や路線によって異なる場合があるため、画面上の日本語表記と収録データを個別に確認しています。

## 公開データの構造

公開するICごとにJSONを1ファイル置きます。主な項目は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| `id` | URLで使うIC識別子 |
| `name` | IC・JCT名 |
| `routeId` | 所属路線ID |
| `kp` | 路線図へ戻る際のKP |
| `center` / `bounds` | 初期表示範囲 |
| `ramps[]` | ランプごとの線形・表示色・方向・出入口情報 |
| `streetView` | Street Viewを開く代表座標と向き |
| `mpOrigin` | 料金所を0mとするメーターポスト表示の基準（対応データのみ） |

ページ本体は `prototypes/ic-ramps/` にあります。公開ビルドは `build-pages.mjs` の許可リストにあるHTML・CSS・JavaScriptと公開承認済みJSONだけをコピーします。このため、同じフォルダに確認中のデータが存在しても自動では公開されません。

## この機能で示せること

- KP路線図から、IC内部のランプという別スケールの情報へ自然に掘り下げられる
- OSM線形を機械抽出しつつ、複雑なICだけ人が確認・補正する運用ができる
- ランプごとに色、名称、方向、代表座標を持たせ、現地確認へ接続できる
- 公開承認したICだけを許可リスト方式で段階公開できる
- 同じページ部品で、単純なICから複雑なJCTまで拡張できる

## 注意事項

- ランプ線形と表示位置は確認用であり、道路管理・測量・規制判断には使用できません。
- Google Street ViewはGoogle LLCが提供する外部サービスです。本プロジェクトはGoogleと提携・承認関係にありません。
- OSM由来の線形を含む場合は、OpenStreetMapのライセンスと帰属表示が適用されます。
